Notes · 开发随笔

为什么我用原生 Canvas 而不是粒子库

副本 / INSTANCE

冲击波需要逐粒子施加初速度、逐帧阻尼回落、结局模式热切换——这些必须拿到粒子实例才能精确控制，顺带省掉一个依赖。

让 AI 生成的小说不像聊天：一份 JSON 协议的好处

模拟人生

上层只认固定 JSON 结构，真实大模型和本地引擎可以无缝互换，接口失败自动回落，界面逻辑一行都不用改。

数据驱动渲染：新增内容只改一个数组

zxy 的模拟人生

卡片、文章页、主题换肤全部由 stories 数组自动生成，加一篇新文章不需要碰 HTML 和 CSS。
