# 倾酒 · 个人作品集

极简风个人作品集页面，单文件、零依赖、零构建。

🔗 **在线访问**：https://qingjiu188.github.io/blog/

## ✨ 特点

- 纯 HTML + CSS + 原生 JS，单文件 `index.html`，双击即可运行
- 极简白底设计，720px 窄栏阅读宽度
- 毛玻璃吸顶导航，滚动入场动画（IntersectionObserver）
- 响应式适配移动端，支持 `prefers-reduced-motion`
- 所有项目附「在线体验 + 查看源码」直达链接
